## 1. 设计理念

### 1.1 瑞士国际极简主义

避风港平台采用瑞士国际风格（Swiss International Style）作为设计基石，强调：

- **清晰的视觉层次**：通过字号、粗细、间距建立信息层级
- **网格系统**：所有元素基于统一的网格对齐
- **无衬线字体**：现代、简洁、易读
- **留白**：适当的空白区域提升可读性和呼吸感
- **几何形状**：使用圆形、方形等基本几何图形

### 1.2 设计约束

| 约束类型 | 规则 | 原因 |
|----------|------|------|
| 颜色 | 禁用纯黑（#000000） | 纯黑过于刺眼，影响阅读舒适度 |
| 颜色 | 禁用紫色/霓虹渐变 | 避免"AI紫色"的俗套风格，保持专业感 |
| 颜色 | 饱和度不超过80% | 高饱和度颜色容易视觉疲劳 |
| 字体 | 禁用Inter | Inter过于通用，缺乏辨识度 |
| 布局 | 禁止Flex百分比计算 | 使用网格系统替代 `calc(33% - 1rem)` |
| 动效 | 仅使用Spring物理引擎 | 提供自然流畅的动画效果 |
| 加载 | 禁止圆形加载器 | 使用骨架屏提升用户体验 |

### 2.3 颜色使用规范

**必须遵循**：

1. **优先使用语义化变量**：使用 `text-primary`、`bg-background` 而非直接使用十六进制值
2. **禁止硬编码颜色**：所有颜色值必须定义在 tailwind.config.ts 中
3. **颜色对比度**：文本与背景对比度至少达到 WCAG AA 标准（4.5:1）
4. **状态一致性**：相同状态（成功/警告/错误）必须使用相同颜色

**禁止**：

1. ❌ 使用纯黑 `#000000`，使用 `#1A1D23` 替代
2. ❌ 使用紫色渐变或霓虹色
3. ❌ 使用高饱和度颜色（饱和度 > 80%）
4. ❌ 在未经评审的情况下引入新颜色

## 3. 字体体系

### 3.1 字体栈

```css
font-family: 'DM Sans', 'Manrope', -apple-system, 'PingFang SC', 'Microsoft YaHei', sans-serif;
```

**字体选择策略**：

| 场景 | 首选字体 | 备选字体 | 原因 |
|------|----------|----------|------|
| 英文 | DM Sans | Manrope | 现代、专业、有辨识度 |
| 中文 | PingFang SC | Microsoft YaHei | 系统字体，性能最优 |
| 回退 | -apple-system | sans-serif | 保证所有环境可用 |

| body | 14px | 20px | 400 | 正文、主要内容 |
| body-lg | 15px | 22px | 400 | 大正文、阅读密集区 |

| 字重 | 使用场景 |

## 4. 间距与布局

### 4.1 间距系统

基于 8px 基准单位的倍数系统：

| 间距令牌 | 值 | 用途 |
|----------|-----|------|
| 0 | 0px | 无边距 |
| 1 | 4px | 紧凑元素间距 |
| 2 | 8px | 元素内边距、小组件间距 |
| 3 | 12px | 中等间距、卡片内边距 |
| 4 | 16px | 标准间距、段落间距 |
| 5 | 20px | 较大间距、区块间距 |
| 6 | 24px | 模块间距、页面内边距 |
| 8 | 32px | 大间距、页面区块分隔 |
| 10 | 40px | 首屏大间距 |
| 12 | 48px | 主要标题间距 |

### 4.2 容器规范

| 容器类型 | 最大宽度 | 内边距 | 用途 |
|----------|----------|--------|------|
| 页面容器 | 1280px | 24px | 主内容区域 |
| 卡片容器 | 100% | 20px | 卡片内容 |
| 紧凑容器 | 100% | 16px | 表单、小组件 |

### 4.3 网格系统

```css
/* 基础网格配置 */
grid-template-columns: repeat(12, 1fr);
gap: 16px;

/* 断点配置 */
- sm: 640px  → 2列
- md: 768px  → 3-4列
- lg: 1024px → 4-6列
- xl: 1280px → 6-12列
```

**布局规则**：

1. **必须使用网格**：所有页面布局优先使用 `grid`，禁止使用 Flexbox 百分比计算
2. **禁止重叠**：每个元素必须独立占据网格空间，禁止元素重叠
3. **Bento网格**：特性区使用 Bento 网格或 Zig-Zag 布局，禁止"3个相等卡片"模式

## 5. 圆角与阴影

### 5.1 圆角系统

| 令牌名称 | 值 | 用途 |
|----------|-----|------|
| sm | 4px | 小元素（Badge、Input） |
| md | 8px | 标准元素（Button、Card） |
| lg | 12px | 大元素（Dialog、Modal） |
| xl | 16px | 全屏容器 |

**使用规则**：

- 按钮、输入框统一使用 `md` (8px)
- 卡片统一使用 `md` (8px)
- 对话框使用 `lg` (12px)

### 5.2 阴影系统

| 令牌名称 | CSS值 | 用途 |
|----------|-------|------|
| shadow-sm | 0 1px 2px 0 rgb(0 0 0 / 0.05) | 轻量悬浮效果 |
| shadow | 0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1) | 标准卡片 |
| shadow-md | 0 4px 6px -1px rgb(0 0 0 / 0.1), 0 2px 4px -2px rgb(0 0 0 / 0.1) | 悬浮卡片 |
| shadow-lg | 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1) | 对话框、弹出层 |

**使用规则**：

- **禁止硬边阴影**：所有阴影必须柔和扩散
- **层级对应**：层级越高，阴影越大
- **禁用内阴影**：`box-shadow: inset` 禁止使用

## 6. 组件库体系

### 6.1 组件分类

| 类别 | 组件 | 文件路径 |
|------|------|----------|
| 基础交互 | Button, Input, Textarea, Label, Checkbox | components/ui/ |
| 布局容器 | Card, Separator, ScrollArea | components/ui/ |
| 导航覆盖 | Accordion, Dialog, DropdownMenu, Popover, Sheet, Tabs, Tooltip | components/ui/ |
| 选择表单 | Select, Avatar, Badge, Alert | components/ui/ |
| 组合高级 | Combobox, Command, Skeleton, Sonner | components/ui/ |

### 6.2 组件设计模式

#### 变体模式（Variant Pattern）

所有组件通过 `variant` 和 `size` 属性控制外观：

```typescript
interface ButtonProps extends React.ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'default' | 'destructive' | 'outline' | 'secondary' | 'ghost' | 'link'
  size?: 'default' | 'sm' | 'lg' | 'icon'
}
```

#### 组合模式（Compound Pattern）

复杂组件使用组合模式，提供灵活的嵌套结构：

```typescript
// Dialog组件示例
<Dialog>
  <DialogTrigger asChild>
    <Button>打开对话框</Button>
  </DialogTrigger>
  <DialogContent>
    <DialogHeader>
      <DialogTitle>标题</DialogTitle>
      <DialogDescription>描述</DialogDescription>
    </DialogHeader>
    {/* 内容 */}
  </DialogContent>
</Dialog>
```

### 6.3 组件使用规范

**必须遵循**：

1. **使用封装组件**：优先使用 `components/ui/` 下的封装组件，禁止直接使用 Radix UI
2. **保持一致性**：相同场景使用相同组件变体
3. **可访问性**：所有交互组件必须支持键盘导航和屏幕阅读器

**禁止**：

1. ❌ 直接使用原生 `<button>` 标签，使用 `<Button>` 组件
2. ❌ 硬编码样式覆盖组件外观
3. ❌ 自定义组件时不遵循设计令牌

## 7. 动画系统

### 7.1 动画令牌

| 动画名称 | 效果 | CSS类名 |
|----------|------|---------|
| fade-in | 淡入 | `animate-fade-in` |
| slide-up | 从下方滑入 | `animate-slide-up` |
| slide-down | 从上方滑入 | `animate-slide-down` |
| slide-left | 从左侧滑入 | `animate-slide-left` |
| slide-right | 从右侧滑入 | `animate-slide-right` |
| scale-in | 缩放进入 | `animate-scale-in` |
| pulse-once | 单次脉冲 | `animate-pulse-once` |

### 7.2 动画性能规则

**必须遵循**：

1. **仅动画 transform 和 opacity**：这两个属性触发 GPU 加速，不触发重排
2. **避免动画 width/height/margin**：这些属性触发重排，性能差
3. **使用 will-change**：对即将动画的元素设置 `will-change: transform, opacity`
4. **尊重用户偏好**：检查 `prefers-reduced-motion`，为禁用动画的用户提供备选

### 7.3 动画时长规范

| 动画类型 | 时长 | 缓动函数 |
|----------|------|----------|
| 微交互（悬停、点击） | 150ms | ease-out |
| 页面过渡 | 250ms | ease-in-out |
| 弹出层（Dialog、Sheet） | 300ms | spring |
| 加载动画 | 800ms | ease-in-out |

## 8. 响应式策略

### 8.1 断点配置

| 断点 | 宽度 | 设备类型 | 布局策略 |
|------|------|----------|----------|
| sm | ≥640px | 手机横向 | 单列或双列 |
| md | ≥768px | 平板 | 3-4列 |
| lg | ≥1024px | 桌面 | 4-6列 |
| xl | ≥1280px | 大屏 | 6-12列 |

### 8.2 移动端优先规范

**必须遵循**：

1. **触摸目标最小44px**：所有可点击元素宽度和高度至少44px
2. **按钮全宽**：移动端按钮默认占满父容器宽度
3. **禁止水平滚动**：任何情况下禁止出现水平滚动条
4. **响应式图片**：图片必须使用 `max-width: 100%`

### 8.3 测试视口

| 视口宽度 | 用途 |
|----------|------|
| 375px | iPhone SE |
| 768px | iPad |
| 1024px | iPad Pro |
| 1440px | 标准桌面 |

## 9. 可访问性

### 9.1 ARIA标准

**必须遵循**：

1. **语义化HTML**：使用正确的HTML标签（`<button>`、`<a>`、`<nav>`等）
2. **ARIA属性**：为自定义组件添加适当的ARIA属性
3. **焦点管理**：确保所有交互元素可通过键盘聚焦
4. **焦点顺序**：Tab键顺序符合用户预期

### 9.2 键盘导航

| 组件 | 键盘操作 |
|------|----------|
| Button | Enter/Space 触发 |
| Input | Tab 切换焦点 |
| Select | Arrow Up/Down 选择 |
| Dialog | Escape 关闭 |
| Tabs | Arrow Left/Right 切换 |

### 9.3 屏幕阅读器支持

**必须遵循**：

1. **替代文本**：所有图片必须有 `alt` 属性
2. **角色声明**：自定义组件必须声明 `role` 属性
3. **状态通知**：动态内容变化必须通知屏幕阅读器
4. **颜色无关**：信息传达不能仅依赖颜色

## 10. 反模式清单

### 10.1 布局反模式

| 反模式 | 描述 | 正确做法 |
|--------|------|----------|
| Flex百分比计算 | `calc(33% - 1rem)` | 使用 Grid 网格系统 |
| 元素重叠 | 多个元素占据相同空间 | 每个元素独立网格区域 |
| 居中Hero布局 | 首屏内容居中显示 | 使用非对称布局 |
| 3个相等卡片 | 特性区使用3个相同大小卡片 | 使用Bento网格或Zig-Zag布局 |

### 10.2 颜色反模式

| 反模式 | 描述 | 正确做法 |
|--------|------|----------|
| 纯黑文本 | `#000000` | 使用 `#1A1D23` |
| 紫色渐变 | AI产品常见的紫色渐变 | 使用品牌主色 |
| 霓虹外发光 | `box-shadow: 0 0 20px purple` | 使用柔和阴影 |
| 硬编码颜色 | 直接在组件中使用十六进制值 | 使用语义化变量 |

### 10.3 字体反模式

| 反模式 | 描述 | 正确做法 |
|--------|------|----------|
| 使用Inter | 过于通用，缺乏辨识度 | 使用DM Sans/Manrope |
| 使用衬线字体 | 正文使用衬线字体 | 仅在特定场景使用 |
| 字号混乱 | 随意使用不同字号 | 遵循字号层级 |
| 字重过度 | 使用300或800+字重 | 限制在400-700 |

### 10.4 动效反模式

| 反模式 | 描述 | 正确做法 |
|--------|------|----------|
| 圆形加载器 | 旋转圆环加载动画 | 使用骨架屏 |
| 动画margin | 动画margin/padding触发重排 | 动画transform/opacity |
| 无限循环动画 | 无意义的持续动画 | 使用脉冲或单次动画 |
| 忽略用户偏好 | 不检查 `prefers-reduced-motion` | 提供动画开关 |
